  kernel slice: legacy uImage + generated FIP trailer + gate magic;
  rootfs: static UBI volume 'squashfs' plus the empty dynamic volume
  'rootfs_data' with vol_flags=autoresize. fstools mount_root finds the
  overlay volume by name and the kernel's first read-write UBIFS
  mount formats it (fs/ubifs/sb.c create_default_filesystem); the
  kernel autoresize grows it to the free PEBs of the slot. That
  path is read from the sources, not measured on this board.
