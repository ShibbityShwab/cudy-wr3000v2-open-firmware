## 2. pci - PARTIAL

Paths: `pci/luofu-pcie.c` (1664), `pci/Kconfig` (50), `pci/README.md` (131).
The driver is the lab `luofu-pcie.c` (sha256 `5629b274...11cd4`) plus a provenance header and one
compile gate, `CONFIG_LUOFU_PCIE_ENABLE_LINK_WRITES` (default n). With the gate off probe is the
read-only inventory and the module compiles no `writel()`; with it on, the RC bring-up is compiled
but never validated. `probe()` returns 0 without `pci_host_probe()` (source `:1484`), so the RC is
not brought up by publishing this file.

```

grep -c '^[[:space:]]*default n' pci/Kconfig               # 2
```
(README's own wording: `grep -n 'default n' pci/Kconfig` -> "both symbols"; it also matches line 25,
which is help text, so the anchored form above is the precise one.)
